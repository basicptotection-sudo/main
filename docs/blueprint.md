# **App Name**: Basic Protection Privée Showcase

## Core Features:

- Basic Layout and Structure: Sets up a Next.js project using the App Router with a professional folder structure, TypeScript, Tailwind CSS, and shadcn/ui.
- Global Layout Components: Implements a global layout with Header and Footer components, and a central configuration for the 'Basic Protection Privée' brand.
- Tailwind CSS Configuration: Configures Tailwind CSS variables and CSS tokens, including styles for buttons, badges, cards, and sections, using a clean and institutional design.
- Metadata API Implementation: Sets up Next.js Metadata API to ensure proper SEO across all pages, integrating OpenGraph and Twitter metadata.
- Sitemap and Robots.txt Generation: Automatically generates a sitemap.xml and implements a robots.txt file for better search engine crawling and indexing.
- JSON-LD Schema Markup: Adds JSON-LD schema markup for WebSite and Organization/LocalBusiness with placeholders for easy modification, enhancing SEO.
- Custom Error Pages: Implements custom 404 and 500 error pages to improve user experience and handle server errors gracefully.

## Style Guidelines:

- Primary color: Marine (#33396D) to convey a sense of security and professionalism.
- Accent color: Blue (#3A7CB0), analogous to marine but brighter, for interactive elements and highlights.
- Muted color: Light blue-gray (#9CB4CD) to offer a soft, neutral tone for backgrounds and less critical UI elements.
- Background color: Very light cyan (#E6F2F7), close in hue to the primary color but nearly desaturated, to provide a subtle and unobtrusive backdrop.
- Body and headline font: 'Inter' (sans-serif) for a modern, clean, and highly readable typeface suitable for an institutional look. Note: currently only Google Fonts are supported.
- Mobile-first layout to ensure responsiveness and optimal viewing experience on all devices.
- Use simple and professional icons that align with the company's services and values.
